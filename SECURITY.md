# Security policy

## Supported content

Security fixes apply to the catalog and Topping versions currently published on `main`. Reports
about an older installed version remain useful when the same behavior still exists in the current
source.

## Private reporting

Do not open a public issue or pull request for an active vulnerability. Use GitHub's private
vulnerability reporting for this repository.

Include:

- affected Topping ID and version;
- affected URL and required account state;
- impact and data exposed or modified;
- minimal reproduction steps; and
- a suggested narrow fix, if available.

Avoid accessing real user data while investigating. Maintainers may remove or disable the affected
catalog entry before publishing a full fix.
